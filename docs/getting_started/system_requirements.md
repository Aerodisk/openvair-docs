# Общие системные требования OpenVAIR

## Операционная система

- Ubuntu 20.04 LTS (рекомендуется), Ubuntu 22.04 LTS (поддерживается)
- Архитектуры: x86_64 (AMD64), aarch64 (ARM64)

## Python

- Python 3.8+
- Используется виртуальное окружение (venv), конфигурируется автоматически

## Аппаратные требования

- Минимум 8 CPU ядер
- 16 GB RAM
- 256 GB постоянной памяти (SSD рекомендуется)

## Особенности установки

- Все зависимости устанавливаются автоматически через install-скрипт проекта
