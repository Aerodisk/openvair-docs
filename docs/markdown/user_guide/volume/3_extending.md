# Увеличение объёма

1. Чтобы увеличить объем виртуального диска, выберете диск, размер которого необходимо
   увеличить, выбрав чекбокс слева напротив существующего виртуального диска.
2. В правом верхнем углу нажмите кнопку «Увеличить объём»
3. В появившемся окне выберете единицу измерения и укажите размер на который нужно
   увеличить размер виртуального диска
4. Нажмите кнопку «Увеличить»
