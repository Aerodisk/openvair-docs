Этот модуль предназначен для управления образами в системе. Образы служат основой для
создания виртуальных машин, поэтому их загрузка, управление и мониторинг очень важны
для работы с системой виртуализации.

## Загрузка образа

Для загрузки нового образа в систему выполните следующие шаги:

1. Перейдите в раздел «Виртуальные образы».
2. В правом верхнем углу, нажмите «Загрузить»
3. При нажатии «Выберете образ» откроется меню выбора образа в вашей файловой системе
   или перетащите с помощью мыши образ для загрузки
4. Выберите хранилище, куда будет загружен образ.
5. Опционально, добавьте описание
   > ![image](/assets/images/image/load_img.png)

Примечание: После загрузки образа его статус будет «новый», и процесс загрузки в
хранилище начнется автоматически.

## Удаление образа

Для удаления образа выполните следующие шаги:

1. Перейдите в раздел «Виртуальные образы».
2. Выберите образ, который вы хотите удалить, выделив слева от него чек-бокс
3. В верхнем правом углу нажмите «Удалить»
   > ![image](/assets/images/image/delete_img.png)

## Присоединение образа

Для привязки образа к виртуальной машине выполните следующие шаги:

1. Перейдите в раздел виртуальные машины.
2. В меню создания или редактирования виртуальной машины перейдите в раздел
   Виртуальные образы
   > ![image](/assets/images/image/attach_img_1.png)
3. Нажмите кнопку «Добавить ВО» и в открывшемся меню выберете образ, который нужно
   добавить к виртуальной машине.
4. Подтвердите привязку образа.
   > ![image](/assets/images/image/attach_img_2.png)

## Отсоединение образа

Для отвязки образа от виртуальной машины выполните следующие шаги:

1. Перейдите в раздел виртуальные машины.
2. В меню редактирования виртуальной машины перейдите в раздел Виртуальные образы
   > ![image](/assets/images/image/detaching_1.png)
3. Нажмите на значок удаления в виде корзины, напротив образа, который нужно удалить.
4. Подтвердите отвязку образа.
5. Сохраните конфигурацию виртуальной машины.
   > ![image](/assets/images/image/detaching_2.png)

## Периодический мониторинг

Модуль автоматически мониторит статус и доступность всех образов в системе.
Если образ недоступен или его статус изменился, система пытается исправить
ситуацию или уведомляет пользователя о проблеме.

## Просмотр информации об образе

Для просмотра подробной информации об определенном образе выполните следующие шаги:

1. Перейдите в раздел «Виртуальные образы».
2. Откроется страница с подробной информацией о каждом образе, включая его статус,
   размер, описание и хранилище.
   > ![image](/assets/images/image/img_page.png)

## Фильтрация и поиск образов

Для удобства работы с образами доступны функции фильтрации и поиска:

1. Используйте поля фильтра для быстрого поиска образов по статусу, размеру или
   хранилищу.
2. Введите ключевые слова в поле поиска для поиска образов по имени или описанию.
