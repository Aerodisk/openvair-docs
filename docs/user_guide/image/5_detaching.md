# Отсоединение образа

Для отвязки образа от виртуальной машины выполните следующие шаги:

1. Перейдите в раздел виртуальные машины.
2. В меню редактирования виртуальной машины перейдите в раздел Виртуальные образы
   > ![image](_static/img/image/detaching_1.png)
3. Нажмите на значок удаления в виде корзины, напротив образа, который нужно удалить.
4. Подтвердите отвязку образа.
5. Сохраните конфигурацию виртуальной машины.
   > ![image](_static/img/image/detaching_2.png)
