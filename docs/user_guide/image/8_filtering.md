# Фильтрация и поиск образов

Для удобства работы с образами доступны функции фильтрации и поиска:

1. Используйте поля фильтра для быстрого поиска образов по статусу, размеру или
   хранилищу.
2. Введите ключевые слова в поле поиска для поиска образов по имени или описанию.
