# SNMP

SNMP (Simple Network Management Protocol) - это стандартный протокол сетевого
управления, который используется для мониторинга и управления сетевыми
устройствами. Он предоставляет средства для сбора информации о состоянии
устройств в сети, таких как серверы, маршрутизаторы, коммутаторы и другие
сетевые устройства. SNMP позволяет администраторам собирать данные о
различных параметрах устройств, таких как загрузка процессора (CPU),
использование оперативной памяти (RAM), доступность сетевых интерфейсов, а
также другие показатели производительности и статусы устройств. Эта
информация может использоваться для мониторинга состояния сети, выявления
проблем и выполнения действий по их устранению, а также для настройки и
управления сетевыми устройствами.

## Описание функционала модуля

Модуль SNMP предоставляет возможность мониторинга и управления различными
аспектами сетевой инфраструктуры. Ниже представлены основные компоненты и их
функции:

### Агент SNMP AgentX

Модуль SNMPAgentx представляет собой реализацию агента SNMP типа AgentX. Этот
агент обеспечивает мониторинг и управление ресурсами сервера, такими как
процессор (CPU), оперативная память (RAM), дисковое пространство и сетевые
интерфейсы. Он регистрирует различные модули для мониторинга состояния этих
ресурсов и предоставляет доступ к данным через SNMP.

## Метрики

### Cpu

Метрика Cpu предоставляет информацию о загрузке процессора (CPU). Он
регистрирует показатели загрузки CPU и предоставляет доступ к этим данным
через SNMP.

### Disks

Метрика Disks предоставляет информацию о дисковых устройствах и их
использовании. Он регистрирует данные о разделах диска, их типе,
местоположении, объеме и использовании и предоставляет доступ к этим данным
через SNMP.

### Networks

Метрика Networks предоставляет информацию о сетевых интерфейсах и их состояни
. Он регистрирует данные о сетевых интерфейсах, их статусе и предоставляет
доступ к этим данным через SNMP.

### Ram

Метрика Ram предоставляет информацию об использовании оперативной памяти (RAM).
Он регистрирует данные о общем объеме оперативной памяти, ее использовании и
доступности и предоставляет доступ к этим данным через SNMP.


## Сценарии использования SNMP

### Мониторинг устройств по SNMP

Для мониторинга устройств по протоколу SNMP можно использовать различные
инструменты, такие как snmpwalk. Ниже приведен пример команды для получения
метрик с устройства по его IP-адресу:

```bash
snmpwalk -v2c -c public 192.168.2.198 1.3.6.1.4.1.54641
```

В данном примере:

- -v2c указывает версию протокола SNMP (версия 2c);
- -c public указывает общественное сообщество (community string) для доступа к устройству;
- 192.168.2.198 - IP-адрес устройства, с которого получаются метрики;
- 1.3.6.1.4.1.54641 - OID (Object Identifier) для запрашиваемых метрик.

OID 1.3.6.1.4.1.54641 зарезервирован за компанией AERODISK, что указывает на то, что эти метрики относятся к устройствам этой компании.

После выполнения данной команды будет получена информация о метриках, доступных на указанном устройстве.
