Здесь представлен пользовательский гайд по управлению вашими хранилищами,
как удаленными, так и локальными.

## Локальные Хранилища

Данное раздел познакомит с тем, как использовать локальное хранилище в системе Open vAIR.

### Получение Информации о физических дисках

Информацию о физических дисках можно получить в виде списка.

Получить список всех физических дисков можно путем запроса по адресу

GET: /storages/local-disks/

### Создание Хранилищ На Локальных Дисках

#### Получить список локальных дисков

Получить список всех доступных локальных дисков можно с помощью запроса
к ендпоинту.

> GET: /storages/local-disks/

Для дальнейшего создания хранилища вам необходимо знать путь свободного
физического диска или партиции локального диска.

#### Создание

Создать хранилище на локальном диске или партиции можно с помощью запроса,
передав путь и указав тип файловой системы.

> POST: /storages/create/

#### Статусы, которые можно получить при создании

Только что созданное хранилище (результат запроса /create/) всегда будет
иметь статус «new».
Получить актуальную информацию о вашем хранилище можно с помощью запроса,
передав id хранилища.

> GET: /storages/{storage_id}/

В результате, вы можете получить хранилище в статусе «available» или «error».

- available - полностью готовое к работе хранилище.
- error - статус хранилища, в ходе создания которого возникла ошибка.

## NFS

Данное раздел познакомит с тем, как использовать NFS хранилище в системе Open vAIR.

### Создание Хранилищ На Удаленной Файловой Системе NFS

#### Создание

Создать хранилище на удаленной файловой системе NFS можно с помощью запроса,
передав ip, путь и версию вашей файловой системы NFS.

> POST: /storages/create/

иметь статус «new».

передав id хранилища.

> GET: /storages/{storage_id}/

В результате, вы можете получить хранилище в статусе «available» или «error».

- available - полностью готовое к работе хранилище.
- error - статус хранилища, в ходе создания которого возникла ошибка.

## Получение информации о хранилищах

Получение информации о ваших хранилищах. Можно получить, как список всех
хранилищ, так и получить информацию об одном конкретном хранилище по его
id.

### Все хранилища

Получить список всех ваших хранилищ можно путем запроса по адресу

> GET: /storages/

### Одно хранилище

Получить одно конкретное хранилище можно с помощью запроса, передав id
конкретного хранилища.

> GET: /storages/{storage_id}/

## Удаление Хранилища

### Удаление

Удалить одно конкретное хранилище можно с помощью запроса, передав id
конкретного хранилища.

> DELETE: /storages/{storage_id}/delete/

### Влияние статуса удаляемого хранилища на процесс

Удалить информацию о хранилище можно, если оно находится в статусе «available» или
«error». То есть, либо доступное для работы хранилище, либо хранилище, в ходе
работы или создания которого произошла ошибка.
