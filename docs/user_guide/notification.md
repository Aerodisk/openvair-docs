# Уведомления

Добро пожаловать в руководство пользователя модуля уведомлений! Это руководство
предназначено для тех, кто будет использовать функционал отправки уведомлений в системе.
Здесь вы найдете информацию о том, как создавать, настраивать и отправлять уведомления
различных типов.

Модуль уведомлений предоставляет удобные и гибкие инструменты для отправки уведомлений
пользователям системы. Следуя этому руководству, вы сможете легко создавать,
настраивать и отправлять уведомления, а также отслеживать их статус.

## Перед использованием

Для использования данного функционала, необходимо указать в конфигурационном файле
проекта(project_config.toml) следующие параметры:

```bash
[notifications]
    [notifications.email]
    smtp_server = 'smtp.yandex.ru'
    smtp_port = 465
    smtp_username = 'your_email@example.com'
    smtp_password = 'your_password'
```

После чего, нужно перезапустить сервисы данного модуля командой:

sudo systemctl restart notification-service-layer.service notification-domain.service

## Типы уведомлений

Модуль уведомлений поддерживает два основных типа уведомлений:

- Электронное письмо (Email)
- SMS(планируется)

## Создание уведомления

Для создания уведомления необходимо:

1. Выбрать тип уведомления: Вам нужно определить, какой тип уведомления вы хотите отправить: электронное письмо или SMS.
2. Указать получателей: Введите адреса электронной почты или номера телефонов получателей уведомления. Вы можете указать несколько адресов, разделив их запятой или точкой с запятой.
3. Задать тему и текст уведомления: Введите тему и текст уведомления в соответствующие поля.
4. Настроить дополнительные параметры: В зависимости от выбранного типа уведомления, вам могут быть доступны дополнительные параметры (например, настройки SMTP для электронного письма).

## Отправка уведомления

После создания уведомления, вы можете отправить его, нажав на кнопку «Отправить».
Система автоматически обработает ваш запрос и отправит уведомление указанным получателям.

## Отслеживание статуса уведомления

После отправки уведомления вы можете отслеживать его статус:

- Отправлено успешно: Уведомление успешно доставлено получателям.
- Ошибка отправки: Возникла ошибка при отправке уведомления. В этом случае, система
  попытается отправить уведомление еще раз или предоставит дополнительную информацию о
  причине ошибки.
