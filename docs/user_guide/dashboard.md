# Dashboard

Этот модуль предоставляет API для получения информации о состоянии узла. Для
мониторинга системы используются инструменты Prometheus и Node Exporter.

Prometheus - это система мониторинга и оповещения с открытым исходным кодом,
которая собирает метрики из различных источников, позволяя администраторам
системы легко отслеживать производительность и доступность своих систем.

Node Exporter - это инструмент для экспорта метрик системы Unix и Linux в
формате, который может быть прочитан Prometheus. Он собирает информацию о
производительности, такую как использование CPU, памяти, дисков и сети, и
предоставляет ее в виде метрик для анализа и мониторинга.

API этого модуля позволяет получать информацию о нагрузке на процессор,
использовании памяти, доступном пространстве на дисках, вводе-выводе операций
в секунду (IOPS), задержке ввода-вывода и пропускной способности сети.

## API

### **Получение информации о состоянии узла**

```bash
GET /dashboard/
```

Этот эндпоинт возвращает информацию о текущем состоянии узла.

### Схема данных

**schemas.NodeInfo**

Эта схема представляет информацию о состоянии узла.
