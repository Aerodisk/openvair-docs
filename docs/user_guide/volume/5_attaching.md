# Монтирование виртуального диска

1. Перейдите в раздел виртуальные машины.
2. В меню создания или редактирования виртуальной машины перейдите в раздел «Диски»
   > ![image](_static/img/volume/attaching_1.png)
3. Нажмите кнопку «Добавить диск»
4. В появившемся окне выберете
   - Выбрать существующий диск из хранилища.
     В данном меню выберете чекбокс слева напротив нужного виртуального диска. После
     чего нажмите «Добавить»

   > ![image](_static/img/volume/attaching_2.png)
   - Создать новый диск (описано в разделе [«Создание нового виртуального диска»](2_creating.md#creating).)
