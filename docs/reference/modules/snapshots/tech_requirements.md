# Технические требования к функционалу снапшотов (snapshots)

## Внешние сервисы и интеграция

- Непоследственная интеграция в модуль виртуальных машин (Virtual Machines)
- PostgreSQL — для хранения данных о снапшотах в базе данных
- Модуль _Event Store_ — сообщения о действиях
- RabbitMQ — взаимодействие между слоями модуля и с _Event Store_ через RPC
- _libvirt_ — управление снапшотами виртуальных машин.
- _QEMU_ — управление снапшотами на дисках.
- Локальная директория — хранение метаданных снапшотов (XML)

## Внутренние ограничения и специфика

- Снапшоты создаются в рамках каждой ВМ.
- Для _**internal**_-снапшотов поддерживается только формат дисков `qcow2`.
- Требуется контроль дерева снапшотов.
- Необходимо контролировать операции со снапшотами через систему статусов с мониторингом.
- При выключении ВМ она пропадает из системы и снапшоты удаляются из **_libvirt_** — 
  необходимо восстанавление снапшотов из метаданных при старте ВМ.
- Недоступны операции со снапшотами для выключенных ВМ (кроме удаления).

## Безопасность и аудит

- Все действия логируются для последующего аудита.
- Все ошибки логируются стандартным логгером с указанием причины ошибки.
- Значимые действия отправляются в _Event Store_.
- При ошибке или пропаже снапшота из системы - он переходит в статус `error`.
