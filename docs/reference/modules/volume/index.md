# Модуль управления виртуальными томами (volume)

Модуль `volume` отвечает за все операции с виртуальными томами (виртуальными дисками) в системе виртуализации OpenVAIR.  
Он реализует создание, удаление, расширение, управление метаданными, мониторинг, а также интеграцию с другими сервисами платформы (storage, VM).
