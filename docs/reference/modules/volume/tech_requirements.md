# Технические требования к модулю виртуальных томов (volume)

## Внешние сервисы и интеграция

- Система хранения (storage) с поддержкой NFS или LocalFS  
- Подключение к брокеру сообщений RabbitMQ (для RPC)
- PostgreSQL для хранения метаданных томов
- Event Store для логирования операций и мониторинга событий
- (Опционально) Модуль виртуальных машин (VM) — требуется для attach/detach

## Внутренние ограничения и специфика

- Форматы томов: только `qcow2` и `raw`
- После создания формат изменить нельзя
- Имя тома уникально в пределах выбранного хранилища
- Нельзя удалить том, если он подключён к ВМ
- Расширение тома возможно только если привязанная VM выключена
- Проверка свободного места выполняется до создания или расширения
- Операции выполняются через RPC между слоями (API, Service, Domain) и с другими модулями
- Вся связь между volume и другими модулями — только по UUID/id и через RPC, без ForeignKey
- Файловые операции требуют доступа к нужному mountpoint (для LocalFS/NFS)

## Безопасность и аудит

- Все неудачные операции фиксируют ошибку и переводят том в статус `error`  
- Операции логируются через event_store для аудита  
- Манипуляции с файлами возможны только в пределах разрешённых директорий
