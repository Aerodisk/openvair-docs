# Технические требования к модулю виртуальных томов (volume)

> Модуль volume устанавливается и запускается в рамках общего инсталлятора OpenVAIR.
> Подробные [общие требования к окружению](../../../getting_started/system_requirements.md).

## Особенности и ограничения volume

- Нельзя удалить том, если он подключён к виртуальной машине
- Формат тома (`qcow2` или `raw`) нельзя изменить после создания
- Поддерживаются только форматы qcow2 и raw
- Для работы необходима архитектура x86_64 или aarch64
- Для установки всех зависимостей используйте стандартный скрипт установки проекта
