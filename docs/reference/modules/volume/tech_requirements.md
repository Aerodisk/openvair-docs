# Технические требования к модулю виртуальных томов (volume)

## Внешние зависимости

- Система хранения (storage) с поддержкой NFS или LocalFS
- Подключение к брокеру сообщений RabbitMQ (для RPC)
- PostgreSQL для хранения метаданных

## Требования к файловой системе

- Для LocalFS — права на создание/удаление файлов на выбранном разделе
- Для NFS — корректно смонтированный экспорт с правами записи

## Ограничения модуля

- Поддерживаемые форматы: только `qcow2` и `raw`
- После создания тома изменить формат невозможно
- Том не может быть удален, если он подключён к виртуальной машине
- Расширение тома возможно только если VM, к которой он подключён, выключена
- Проверка свободного места в storage выполняется до операции
  создания/расширения

## Особенности интеграции

- Все операции (создание, удаление, расширение, изменение) выполняются через
  RPC-команды между слоями и модулями (volume, storage, VM)
- Для корректной работы требуется доступность всех сервисов (RabbitMQ, storage,
  event_store)
