# Технические требования к модулю шаблонов (template)

## Внешние сервисы и интеграция

- PostgreSQL для хранения метаданных шаблонов
- RabbitMQ — взаимодействие между модулями (template, volume, storage) через RPC
- Файловое хранилище (LocalFS/NFS/iSCSI)
- Сервис хранения (storage) — хранит физические файлы шаблонов
- Модуль дисков (volume) — использует шаблоны для создания новых томов

## Внутренние ограничения и специфика

- Поддерживаются только форматы `qcow2` и `raw`
- Имя шаблона уникально в пределах storage
- Нельзя удалить или редактировать шаблон, если он используется томами (
  backing-файл)
- Вся связь между шаблонами и другими сущностями — только по UUID/id и через RPC
- Файлы шаблонов всегда хранятся в storage, а не в template
- Проверка на занятость шаблона/удаляемость выполняется через межмодульные
  RPC-запросы

## Безопасность и аудит

- Все операции логируются через централизованный event_store
- Ошибки переводят шаблон в статус `error` с деталями
- Доступ к файлам ограничен заданными директориями
