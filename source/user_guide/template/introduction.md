# Введение

Модуль `template` отвечает за централизованное управление шаблонами томов (`volume templates`) в платформе виртуализации.  
С помощью шаблонов пользователи и администраторы могут создавать новые виртуальные тома (диски) на основе заранее 
подготовленных, стандартизированных образов (`qcow2`), что ускоряет развертывание типовых и корпоративных конфигураций, снижает вероятность ошибок, повышает однородность инфраструктуры.
